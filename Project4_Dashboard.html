Two Genuine Engine Bugs Discovered by This Validation Suite

🐛 Bug 1 — Son-only Asaba branch missing

When a son was present without any daughter, the engine's residuary (Asaba) logic had no matching branch. The son silently received 0 instead of the full residue.

Affected: 363 of 5,000 simulated cases (7.3%)

Fix applied: Added elif has_son and not has_daughter branch assigning the son the full residue after Furud heirs are served.

🐛 Bug 2 — Spouse-only Radd fallback missing

When a spouse was the sole heir with no other Furud or Asaba heirs present, the Radd logic correctly excludes spouses from sharing surplus with other heirs — but had no fallback for when no other heir exists at all.

Affected: 163 of 5,000 simulated cases (3.3%)

Fix applied: Added fallback — when spouse is the only heir present, the full residue reverts to the spouse via Radd (no other claimant exists).
